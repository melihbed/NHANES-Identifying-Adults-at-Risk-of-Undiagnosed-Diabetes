# Identifying Adults at Risk of Undiagnosed Diabetes

A screening model that ranks U.S. adults **with no prior diabetes diagnosis** by their
probability of having a **diabetes-range HbA1c (≥ 6.5 %)**, using only inputs that are
routinely available at a primary-care visit.

> Screening / research tool. It does **not** provide a clinical diagnosis.

**Data:** NHANES August 2021 – August 2023 (CDC / National Center for Health Statistics) —
[datapage](https://wwwn.cdc.gov/nchs/nhanes/search/datapage.aspx?Cycle=2021-2023).

---

## Research question

> Among U.S. adults who report no previous diabetes diagnosis, can routinely available
> demographic and body-measurement characteristics identify individuals with a
> diabetes-range HbA1c measurement?

## Headline result

| | Value |
|---|---|
| Analytical cohort | **4,698** adults (20+, no prior Dx, HbA1c measured, not pregnant) |
| Outcome prevalence | 2.5 % unweighted / **2.0 % survey-weighted** |
| Model | Calibrated, class-weighted **logistic regression** (6 features) |
| Held-out test discrimination | **ROC-AUC 0.84**, PR-AUC 0.074 (≈ 3× the 0.024 no-skill rate) |
| Calibration | Brier 0.024 (Platt-scaled) |
| Operating point (80 % target recall) | **Recall 0.96 (22/23)**, specificity 0.69, precision 0.07, flags 33 % of adults |
| Strongest risk signals (odds ratios) | waist circumference 2.9 · age 2.1 · low education 2.0 · Non-Hispanic Black 1.9 |

**Interpretation.** As a first-stage triage filter, sending the ~1 in 3 highest-risk adults
for a confirmatory HbA1c would have caught 22 of 23 undiagnosed diabetes-range cases in the
test sample. With only 23 test positives the recall estimate is wide — this is a
**proof of concept**, not a validated device.

## Approach

```
01_data_preparation      merge 4 NHANES modules → eligibility cohort → outcome → validate vs CDC benchmark
02_exploratory_analysis  class imbalance · missingness (MAR) · distributions · MWU / χ² / Cramér's V / Spearman
03_modeling              baselines → feature selection → model family → tuning → calibration → threshold → test
src/                     the same logic, packaged and unit-tested (11 tests)
dashboard/               star-schema extracts + build spec for Tableau / Power BI
reports/                 model card, metrics JSON, figures
```

### Key decisions and why

| Decision | Reason |
|---|---|
| Cohort minimum age **20**, not 18 | education variable (`DMDEDUC2`) is only collected for 20+; the 231 excluded 18–19 y/o had zero positives |
| Outcome = **HbA1c ≥ 6.5 % only** | avoids the separate fasting-glucose subsample weight; documented under-count vs CDC's combined definition (2.0 % vs 4.5 %) |
| Primary metrics = **PR-AUC, recall, calibration** — never accuracy | at 2.5 % prevalence a "predict everyone negative" model scores 97.5 % accuracy |
| **Drop BMI, keep waist circumference** | Spearman ρ = 0.89 between them; waist alone matched BMI+waist on CV PR-AUC and keeps coefficients interpretable |
| **Class weighting**, not SMOTE / undersampling | preserves the data-generating process and composes cleanly with probability calibration |
| **Logistic regression** over tree ensembles | RF and HistGB collapsed to the majority class (recall ≈ 0) on 93 positives; LR won PR-AUC/ROC-AUC and yields odds ratios |
| Threshold chosen on **training out-of-fold** scores | the 940-row test set (23 positives) is scored exactly once |

## Reproduce it

```bash
make setup        # python3.11 venv + deps + Jupyter kernel
make all          # data → train → dashboard → tests

# or individually
python -m src.pipeline      # fit, calibrate, evaluate → models/ + reports/
python -m src.dashboard     # rebuild dashboard/data/*.csv
make notebooks             # execute 01 → 02 → 03 in place
pytest
```

Raw NHANES `.xpt` files are committed under `dataset/`, so the pipeline runs offline.
Tested on Python 3.11 (`requirements-lock.txt` has exact versions).

## Limitations

- **Outcome scope.** HbA1c-only; misses fasting-glucose-only undiagnosed cases.
- **Small positive class.** 116 positives total / 23 in test → wide confidence intervals on every minority-class metric.
- **Observational, cross-sectional.** Odds ratios are associations, not causal effects; the model is not calibrated to any specific clinical population.
- **Survey design** (strata / PSU / weights) is used for the prevalence sanity check but not folded into the model's inference.
- **Low precision by design.** A screening filter, not a diagnostic — every flag needs a confirmatory lab test.
